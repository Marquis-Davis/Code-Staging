# The 2X Ledger

Mobile-first educational site for 2X leveraged ETF charts, risk education, and hypothetical return examples.

- Domain: https://the2xledger.com
- Hosting: Cloudflare Pages
- Production branch: `the-2x-ledger-site` of `Marquis-Davis/Code-Staging`, independent from `main`.
- Static HTML/CSS/JavaScript with no build dependencies.

## Safety
Only publish real price-chart screenshots. Never publish personal Schwab balances, proprietary levels, actual fills, or strategy drawings. All example profits are labeled hypothetical; check dates and ETF price adjustment when updating. Social links currently assume @The2XLedger across networks and must be verified against the final profiles before public promotion.
